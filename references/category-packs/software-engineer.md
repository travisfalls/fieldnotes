# Software Engineer

Categories for people who design, build, and run software.

- **Architecture**: System design, technical direction, trade-off decisions
- **Backend**: APIs, services, business logic, server-side performance
- **Frontend**: UI implementation, client-side state, accessibility, web performance
- **Mobile**: iOS, Android, cross-platform apps, offline behavior
- **Data**: Schemas, queries, migrations, pipelines, storage performance
- **DevOps & Infrastructure**: CI/CD, cloud, deployment, observability, reliability
- **Testing & Quality**: Automated tests, test strategy, debugging, code review
- **AI & Tooling**: AI-assisted development, developer tools, automation
- **Leadership & Mentoring**: Leading efforts, mentoring, raising the team's bar
- **Learning & Growth**: New skills, technologies, and domains picked up
